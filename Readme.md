# 💬 ChatSphere - Real-Time Chat Application

A modern real-time chat application built using Python, Flask, Flask-SocketIO, HTML, CSS, and JavaScript.

---

# 🚀 Features

- 🔐 User Authentication (Login/Register)
- 💬 Real-Time Messaging
- 🤖 AI Chatbot Replies
- 👤 Profile Picture Upload
- 🧠 Typing Indicator
- 😊 Emoji Support
- 🔔 Notifications
- 🏠 Chat Rooms
- 🔍 Search Chats
- 📱 Responsive Design
- 🎨 Modern Animated UI
- 🌙 Dark Theme Interface

---

# 🛠️ Technologies Used

- Python
- Flask
- Flask-SocketIO
- Flask-Login
- SQLAlchemy
- HTML5
- CSS3
- JavaScript
- SQLite

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/real-time-chat-app.git
```

---

## 2️⃣ Open Project Folder

```bash
cd real-time-chat-app
```

---

## 3️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Run Application

```bash
python app.py
```
